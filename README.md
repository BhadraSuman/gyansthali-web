# Gyan Sthali Public School, Kalajharia, Jamtara

A modern, visually rich, fully responsive bilingual website and digital platform prototype built for **Gyan Sthali Public School, Kalajharia, Karmatanr Vidyasagar, Jamtara, Jharkhand**.

Designed by **Uddipta Tech Solution**, this prototype is built on the **Google Stitch Design System** (*"Prestigious Heritage & Modern Vitality"*) using **Next.js (App Router)**, **Tailwind CSS**, and **Google Fonts (Newsreader & Outfit)**.

## 🎨 Google Stitch Design System: "Prestigious Heritage & Modern Vitality"

Integrated from Stitch Project `11268955054141769457`:
- **Display & Section Headlines:** `Newsreader` (Refined, literary academic serif conveying institutional trust).
- **Interface & Body Typography:** `Outfit` (Clean, contemporary geometric sans for mobile readability).
- **Color Palette:**
  - **Deep Royal Navy (`#132A54` / `#00153A`):** Discipline, authority, governance, and institutional legacy.
  - **Warm Academic Amber (`#D97706` / `#FE932C`):** Flame of knowledge, honor rolls, admissions CTAs.
  - **Deep Sage & Forest Green (`#047857`):** Campus life, moral growth, verification badges.
  - **Warm Canvas (`#FDFBF7`):** Refined tactile paper tone.
  - **Crisp White (`#FFFFFF`):** High-contrast cards with micro-strokes (`#E8E3DA`).

## 💼 Digital School Platform (Uddipta Tech Solution Showcase)

Positioned as a complete digital platform for modern schools:
1. **Public Website:** Responsive on Indian 4G Android networks, bilingual toggle, WhatsApp CTAs.
2. **Official Notice Board:** Dynamic circulars (Admissions, Exams, Annual Function, RTE Quota).
3. **Faculty Directory:** "Meet Our Teachers" structured cards ready for school staff profiles.
4. **Interactive Portal Previews (Modals):**
   - **Parent Portal:** Daily attendance (96.4%), homework tracker, report cards, fee receipts.
   - **Teacher & Admin Console:** Admissions leads, class attendance, 1-click WhatsApp broadcasts, digital circulars.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run local development server
npm run dev

# 3. Production build
npm run build
npm start
```
